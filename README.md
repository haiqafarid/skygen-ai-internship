🧠 Project 1: Skygen AI Internship — Prompt Engineering

Overview

This project demonstrates 15 prompting techniques and their practical applications. Each technique focuses on a different way to structure instructions, provide context, guide responses, or improve output consistency.

Prompting Techniques Covered

No.	Technique	Purpose
1	Zero-Shot Prompting	Perform a task without examples
2	Few-Shot Prompting	Guide responses using examples
3	Role Prompting	Assign a role or expertise to the AI
4	Chain-of-Thought Prompting	Encourage structured problem-solving
5	Instruction Prompting	Provide clear task instructions
6	Contextual Prompting	Supply relevant background information
7	Persona Prompting	Define a particular perspective or persona
8	Constraint-Based Prompting	Set boundaries and limitations
9	Output Formatting	Specify the required response structure
10	Iterative Prompting	Refine outputs through multiple iterations
11	Self-Critique Prompting	Review and improve an initial response
12	Comparative Prompting	Compare alternatives or approaches
13	Task Decomposition	Break complex tasks into smaller steps
14	Error Analysis Prompting	Classify and investigate prediction errors
15	Combined Prompting	Combine multiple prompting techniques

Error Analysis Example

Input:

* Actual = 1
* Predicted = 0
* Confidence = 0.76

Expected classification: High-confidence false negative.

This example demonstrates how a structured prompt can classify a machine-learning prediction error according to predefined criteria.

Key Learning Outcomes

* Prompt design and refinement
* Context and instruction structuring
* Output control and formatting
* Task decomposition
* Prediction-error classification
* Practical applications of prompting in AI and Data Science

🌿 Project 2: Willow & Sage — AI Image & Content Workflow

Overview

Willow & Sage is a fictional natural skincare brand used to demonstrate how generative AI can support creative content production and marketing workflows.

Project Components

* Brand Brief: Brand concept, target audience, and visual direction.
* AI-Generated Images: Product, ingredient, skincare, and lifestyle concepts.
* Prompt Log: Prompts and available generation details.
* Image Iterations: Three-image comparisons and prompt refinements.
* Manual Editing Evidence: Before-and-after records for visual refinement.
* Copywriting Tracker: AI drafts, human-edited copy, and editing rationale.
* Promotional Video: A short promotional video draft.
* Workflow Report: Documentation of the process, limitations, and observations.
* AI Disclosure and Credits: Transparency notes and relevant asset credits.

Workflow

1. Define the brand identity and creative direction.
2. Develop prompts for visual content.
3. Generate and review image concepts.
4. Refine prompts and compare iterations.
5. Document manual edits.
6. Develop and human-edit marketing copy.
7. Prepare promotional content.
8. Document limitations and responsible AI practices.

Key Learning Outcomes

* Generative AI for visual content creation
* Prompt refinement and iteration
* Creative workflow documentation
* AI-assisted copywriting
* Human review and editing
* AI transparency and limitations
